# Models
Trained weights are not part of this repository (see the licence notes in the main README). Train your own with `scripts/phase5_gtsdb.ps1` (see `docs/PHASE5.md`).
By default the app uses the newest `sanketra_*.pt` in your data folder (`%USERPROFILE%\SanketraData\models`, set by `SANKETRA_HOME`). To force a specific file set the `SANKETRA_MODEL` environment variable to its path for the session.
